# 💼 Responsive Internship Board

A responsive and beginner-friendly internship listing website built using **HTML, CSS, and Vanilla JavaScript** without any external frameworks.

The platform allows students to explore internship opportunities, search by internship title or company name, and filter internships based on different domains.

## 🚀 Features

- **Responsive Design:** Works on mobile, tablet, and desktop.
- **Internship Listings:** Displays internship details using reusable JavaScript objects.
- **Search Functionality:** Search internships by title or company name.
- **Domain Filtering:** Filter opportunities by Web Development, Python, Data Science, UI/UX Design, and Java.
- **Empty State:** Displays a message when no matching internships are found.
- **Error Handling:** Includes error messages and basic error handling.
- **Keyboard Accessibility:** Supports keyboard navigation and visible focus indicators.
- **Dynamic Cards:** Internship cards are generated using JavaScript DOM manipulation.
- **Reset Filters:** Clear search and domain selections easily.

## 🛠️ Technologies Used

- HTML5 – Page structure and semantic elements.
- CSS3 – Styling, responsive layouts, and media queries.
- JavaScript (Vanilla JS) – Search, filtering, DOM manipulation, and event handling.

## 🔍 How It Works

1. Internship information is stored in a reusable JavaScript array of objects.
2. JavaScript dynamically generates internship cards.
3. Users can search by internship title or company name.
4. Users can select a domain to filter internships.
5. The `filter()` method returns matching internship records.
6. Event listeners update the displayed results whenever users interact with the search or domain controls.
